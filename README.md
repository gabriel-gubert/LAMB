# LAMB

**L**LM-**A**ssisted Code **M**igration **B**ot

## The Migration Challenge

Migrating code that uses an API in legacy versions to current API versions is a complex, time-consuming, and error-prone process. This is due to significant changes in APIs, object models, and underlying frameworks. Manual migration requires extensive developer effort, deep domain knowledge of both platforms, and introduces a high risk of bugs.

### Approach: **L**LM-**A**ssisted Code **M**igration **B**ot (LAMB)

LAMB is a Python package that automates this migration using Large Language Models (LLMs). It intelligently analyzes the source V1.0 code, generates precise, data-driven migration rules based on official documentation, and uses these rules to instruct an LLM to generate the equivalent, modern code.

---

## How It Works

The migration process follows these steps:

1.  **Legacy Code Input**: The user provides the legacy script to be migrated.
2.  **Parse & Analyze**: An ANTLR4-based parser creates an Abstract Syntax Tree (AST) of the code, identifying all types, methods, and expressions.
3.  **Curate Rules**: The system looks up every identified object and method in internal data tables that map legacy API members to their new counterparts.
4.  **Prompt LLM**: A detailed, context-rich prompt is dynamically generated. This prompt includes the original code and the specific, curated rules relevant to that code.
5.  **Generate Migrated Code**: The LLM processes the prompt and returns the migrated code, adhering strictly to the provided rules.

---

## Core Technology

### Data-Driven Rule Curation

The system's accuracy is grounded in data tables generated by parsing API documentation. These tables provide the ground truth for all migration rules, ensuring the LLM's output is based on facts, not just its generalized training data.

### Dynamic Prompt Generation

LAMB builds a powerful prompt at runtime. By providing the LLM with the original code and a precise set of migration instructions, we constrain the model to follow a fact-based conversion path. This significantly minimizes errors and "hallucinations."

**Simplified Prompt Example:**
```plaintext
-- LLM PROMPT --

TASK: Migrate the following legacy code in an old API version to the current API version based ONLY on the rules provided.

RULES:
    1. Method 'createMesh3D' from 'Graphics3D' is OBSOLETE. No direct replacement exists.
    Additional Notes: 'Mesh3D' objects are now created using specific constructor methods. For example, use 'Graphics3D.Sphere(radius, segments)' to create a Sphere.

    2. Method 'setPosition' from 'SceneTree' is OBSOLETE. No direct replacement exists.
    Additional Notes: Position is now a property of 'Node' objects and can be got/set directly.

V1.0 CODE:
...
```

## Integration & Usage

### Jupyter AI Integration
LAMB registers as a custom provider in Jupyter AI, allowing for easy invocation via a magic command directly within a notebook.


```
# Use the magic command on a cell containing V1 code:
%%ai LAMB:vLLMigrate

Sub createSphere()
    ' 1. Create the Mesh3D as a Sphere.
    Dim mesh_3d As Mesh3D = Graphics3D.createMesh3D("Sphere", 5, 32)

    ' 2. Add the Mesh3D to the SceneTree.
    SceneTree.addNode(mesh_3d)
    SceneTree.setPosition(mesh_3d, [0, 10, 5])
End Sub
```

### Model Agnostic Configuration
Powered by vLLM, LAMB is model-agnostic. Any model compatible with the OpenAI API standard can be easily configured in a simple TOML file.

```toml
# ~/.config/LAMB/LAMB.toml

[vllm]
model = "local-model/Meta-Llama-3-8B-Instruct"
host = "127.0.0.1"
port = "8000"
verbose = true

[openai]
model = "gpt-5-nano"
api_key = ""
verbose = true
```

## Migration Example

### Original V1.0 Code
Sub createSphere()
    ' 1. Create the Mesh3D as a Sphere.
    Dim mesh_3d As Mesh3D = Graphics3D.createMesh3D("Sphere", 5, 32)

    ' 2. Add the Mesh3D to the SceneTree.
    SceneTree.addNode(mesh_3d)
    SceneTree.setPosition(mesh_3d, [0, 10, 5])
End Sub

### Migrated V2.0 Code
Sub createSphere()
    ' 1. Create a Sphere.
    Dim sphere As Sphere = new Graphics3D.Sphere(5, 32)
    Set sphere.position = [0, 10, 5]

    ' 2. Add a Sphere to the SceneTree.
    SceneTree.addNode(sphere)
End Sub

## Collaborative Feedback Loop

We aim to create a powerful feedback loop to continuously enhance LAMB's accuracy.

* **Capture Data**: As teams use the tool, it can log the original input, the generated output, and the final, user-corrected version.
* **Build Dataset**: Over time, this creates a high-quality, "gold standard" dataset of validated migration pairs.
* **Refine & Improve**: This dataset will be invaluable for fine-tuning the underlying models and the rule-generation logic, making the tool progressively smarter.

## Roadmap

Our future development plans include:
